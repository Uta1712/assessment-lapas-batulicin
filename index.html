WHOQOL

Kuesioner kualitas hidup

6.1. Bagaimana menurut anda kualitas hidup anda?
6.2. Seberapa puas anda terhadap kesehatan anda?
6.3. Seberapa sering rasa sakit fisik anda mencegah anda dalam beraktivitas sesuai kebutuhan anda?
6.4. Seberapa sering anda membutuhkan terapi medis untuk dapat berfungsi dalam kehidupan sehari-hari anda?
6.5. Seberapa sering anda menikmati hidup anda?
6.6. Seberapa sering anda merasa hidup anda berarti?
6.7. Seberapa sering anda mampu berkonsentrasi?
6.8. Secara umum, seberapa aman anda rasakan dalam kehidupan anda sehari-hari?
6.9. Seberapa sehat lingkungan dimana anda tinggal (berkaitan dengan sarana dan prasarana)
6.10. Apakah anda memiliki vitalitas yang cukup untuk beraktivitas sehari2?
6.11. Apakah anda dapat menerima penampilan tubuh anda?
6.12. Apakah anda memiliki cukup uang untuk memenuhi kebutuhan anda?
6.13. Seberapa jauh ketersediaan informasi bagi kehidupan anda dari hari ke hari?
6.14. Seberapa sering anda memiliki kesempatan untuk bersenang-senang /rekreasi?
6.15. Seberapa baik kemampuan anda dalam bergaul?
6.16. Seberapa puaskah anda dengan tidur anda?
6.17. Seberapa puaskah anda dengan kemampuan anda untuk menampilkan aktivitas kehidupan anda sehari-hari?
6.18. Seberapa puaskah anda dengan kemampuan anda untuk bekerja?
6.19. Seberapa puaskah anda terhadap diri anda?
6.20. Seberapa puaskah anda dengan hubungan personal / sosial anda?
6.21. Seberapa puaskah anda dengan kehidupan seksual anda?
6.22. Seberapa puaskah anda dengan dukungan yang anda peroleh dari teman anda?
6.23. Seberapa puaskah anda dengan kondisi tempat anda tinggal saat ini?
6.24. Seberapa puaskah anda dengan akses anda pada layanan kesehatan?
6.25. Seberapa puaskah anda dengan transportasi yang harus anda jalani?
6.26. Seberapa sering anda memiliki perasaan negatif seperti ‘feeling blue’ (kesepian), putus asa, cemas dan depresi?

URICA

University of Rhode Island Change Assessment

1. Sejauh yang Saya ketahui, Saya tidak mempunyai masalah yang memerlukan suatu perubahan
2. Saya pikir Saya mungkin siap untuk suatu perbaikan pada diri Saya
3. Melakukan sesuatu tentang masalah yang telah lama mengganggu Saya
4. Mungkin akan bermakna untuk mengerjakan masalah Saya
5. Saya bukan yang bermasalah. Tidak masuk akal bagi Saya untuk berada di sini
6. Saya khawatir bahwa Saya akan kembali slip ke suatu masalah yang telah Saya ubah. Jadi, Saya di sini untuk mencari pertolongan
7. Akhirnya Saya sedang melakukan sesuatu terhadap masalah Saya
8. Saya telah berpikir bahwa Saya mungkin ingin mengubah sesuatu tentang diri Saya
9. Saya telah berhasil dalam mengerjakan masalah Saya tapi Saya tidak yakin Saya dapat mempertahakan upaya ini sendiri
10. Ada saatnya masalah Saya sulit tapi Saya sedang mengerjakannya
11. Berada di sini cukup banyak membuang waktu bagi Saya karena masalah ini tidak ada hubungannya dengan Saya
12. Saya berharap tempat ini dapat membuat Saya lebih memahami diri Saya
13. Saya kira Saya memiliki kesalahan tapi tidak ada sesuatu yang benar-benar harus Saya ubah
14. Saya benar-benar bekerja keras untuk berubah
15. Saya memiliki masalah dan Saya pikir Saya harus mengerjakannya
16. Saya tidak menindaklanjuti apa yang telah Saya ubah dan harapkan, dan Saya di sini untuk mencegah kekambuhan dari masalah ini
17. Walau Saya tidak selalu berhasil dalam berubah, paling tidak Saya mengerjakan masalah Saya.
18. Saya pikir sekali Saya telah menyelesaikan masalah Saya akan terbebas, tapi kadang Saya masih berjuang dengan masalah tersebut
19. Saya berharap Saya memiliki lebih banyak ide untuk menyelesaikan masalah Saya.
20. Saya sudah mulai mengerjakan masalah Saya tapi Saya ingin mendapatkan bantuan.
21. Mungkin tempat ini akan dapat menolong Saya.
22. Saya mungkin memerlukan sesuatu untuk mendorong Saya sekarang mempertahankan perubahan yang telah Saya lakukan
23. Saya mungkin merupakan bagian dari masalah, namun Saya tidak benar-benar berpikir bahwa Saya memang bagian dari masalah tersebut
24. Saya berharap seseorang di sini mempunyai beberapa nasihat untuk Saya.
25. Siapa saja dapat bicara tentang perubahan; Saya benar-benar sedang melakukan sesuatu tentang hal ini.
26. Semua pembicaraan tentang psikologi membosankan. Mengapa orang tidak bisa saja melupakan masalah mereka?
27. Saya di sini untuk mencegah diri Saya dari kekambuhan terhadap masalah Saya.
28. Sangat membuat frustrasi, namun saya pikir Saya akan kembali mengalami (rekurensi) dari masalah yang Saya pikir telah selesai.
29. Saya memiliki kekhawatiran begitu juga orang di sebelah Saya. Mengapa Saya harus menghabiskan waktu memikirkan mereka?
30. Saya sedang secara aktif berusaha mengerjakan masalah Saya
31. Saya lebih memilih menyesuaikan diri dengan kesalahan Saya daripada mencoba mengubahnya.
32. Setelah semua yang telah Saya lakukan untuk berusaha dan mengubah masalah, seringkali masalah kembali dan menghantui Saya
